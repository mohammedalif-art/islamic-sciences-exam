# نظام إعداد الأسئلة الامتحانية
جامعة كربلاء – كلية العلوم الإسلامية

نظام عربي لإعداد وتنسيق الأسئلة الامتحانية للأقسام:
- قسم علوم القرآن والتربية الإسلامية
- قسم اللغة العربية
- قسم الفقه وأصوله

يتضمن معاينة A4، حساب الدرجات، الفروع، الحفظ المحلي، تصدير/استعادة المسودة، والطباعة أو الحفظ بصيغة PDF.
